# Little Bit — Design System v5

## Принципи
Редакційний темний інтерфейс: обкладинки й типографіка несуть ієрархію, лінії — лише структура.
Кожне число показується один раз. Жодних декоративних блобів, скла чи градієнтів без змісту.

## Токени (`src/styles/global.css`)
| Токен | Значення | Для чого |
|---|---|---|
| `--bg` | #08090b | тло |
| `--surface` | #101216 | панелі |
| `--ink` / `--muted` / `--faint` | #f2f0e9 / #a7abb3 / #858a93 | текст, усі ≥ 4.5:1 |
| `--accent` | #f2d448 | головна дія, акценти |
| `--st-done` | #56d391 | готово, завершений етап |
| `--st-early` | #5ca9ff | ранній доступ |
| `--st-progress` | #b38cff | у роботі |
| `--st-fund` | #f2a94b | збір коштів |

## Типографіка
Unbounded для заголовків і чисел (`.num`), Manrope для тексту й інтерфейсу.

## Спільні елементи
`.container`, `.section`, `.section-head`, `.eyebrow`, `.btn` / `.btn--primary` / `.btn--sm`,
`.link`, `.chip`, `.status` (колір через `--state`), `.bar`, `.game-grid`, `.crumbs`, `.page`.

## Статуси й етапи
Підписи й кольори статусів — лише в `src/utils/status.ts`.
Етапи на картці: зелений = завершено, жовтий = у роботі, порожня доріжка = не розпочато.
