# Little Bit — Design System v6

## Принципи
Кінематографічний темний інтерфейс, як у стрімінгах: арт гри несе настрій, обкладинки й логотипи — ієрархію.
Тло кожної сторінки підфарбовується кольором гри (`--tint`), керування — білі й скляні «пігулки».
Кожне число показується один раз.

## Кінематографічний шар (`src/styles/cinema.css`, `src/components/cinema/`)
- `Nav.astro` — плаваюча навігація-пігулка; на телефоні ще нижня панель дій.
- `HeroCarousel.astro` — карусель головної: банер, логотип, мета-рядок, дії; змінює `--tint`. `?slide=N` відкриває слайд і ставить паузу.
- `Row.astro` + `Poster.astro` — горизонтальні ряди постерів зі статусом і смужкою прогресу.
- `src/lib/art.ts` — банер і логотип гри з LBK Launcher (запасний банер — `library_hero` зі Steam) і колір `--tint`, порахований із банера під час збірки.
- Спільні класи: `.c-btn` / `.c-btn--glass` / `.c-btn--fund`, `.c-group`, `.c-meta`, `.c-badge`, `.c-logo`, `.c-title`, `.c-panel`, `.c-label`, `.c-row`, `.c-track`, `.c-wrap`.
- Шрифти шару: DM Sans (текст і керування), Archivo (назва гри, якщо немає логотипа).

## Токени (`src/styles/global.css`)
| Токен | Значення | Для чого |
|---|---|---|
| `--bg` | #08090b | тло |
| `--surface` | rgba(16,14,20,.55) | скляні панелі (крізь них видно колір гри) |
| `--ink` / `--muted` / `--faint` | #f6f4f6 / білий 72% / білий 58% | текст |
| `--accent` | #f4f1f4 | головна дія (біла пігулка), активні фільтри |
| `--st-done` | #56d391 | готово, завершений етап |
| `--st-early` | #5ca9ff | ранній доступ |
| `--st-progress` | #b38cff | у роботі |
| `--st-fund` | #f2a94b | збір коштів |

## Типографіка
DM Sans для всього інтерфейсу; Archivo — для назви гри, якщо немає логотипа. Великі заголовки без капсу; капсом лише дрібні мітки.

## Спільні елементи
`.container`, `.section`, `.section-head`, `.eyebrow`, `.btn` / `.btn--primary` / `.btn--sm`,
`.link`, `.chip`, `.status` (колір через `--state`), `.bar`, `.game-grid`, `.crumbs`, `.page`.
Кнопки й фільтри — «пігулки» (border-radius 9999px), панелі — заокруглені скляні (radius 12–18px, blur).

## Статуси й етапи
Підписи й кольори статусів — лише в `src/utils/status.ts`.
Етапи на картці: зелений = завершено, білий = у роботі, порожня доріжка = не розпочато.
