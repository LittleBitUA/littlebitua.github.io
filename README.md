# Little Bit — редизайн v5

Окрема тестова копія. Не змінює ні `landing2025`, ні попередній редизайн.

## Запуск
- `RUN_SITE.bat` або `npm run dev` — локальний сервер.
- `BUILD_SITE.bat` або `npm run build` — статична збірка в `dist/`.

## Що змінилось порівняно з редизайном 2026
- Прибрано Tailwind і всі шари перевизначень з `!important`. Уся система — у `src/styles/global.css`, стилі блоків — у самих компонентах.
- Новий перший екран: заголовок із голосом команди, три цифри без дублювання, стіна обкладинок ігор, у які можна грати.
- Повний каталог із пошуком і фільтрами на головній, новий фільтр «Можна грати», стан фільтрів у URL.
- Картка показує етапи (переклад, редактура, текстури) сегментами: видно, що ранній доступ часто має 100% тексту.
- Легенда статусів над каталогом, пояснення «Чому ранній доступ?» і прозорість зборів на сторінці гри.
- Кнопка «Грати» веде просто в лаунчер і показується лише іграм, у які реально можна грати.
- На сторінці гри повернуто серію в навігації, попередню/наступну гру і дату релізу; розділи нумеруються автоматично.
- Контраст дрібного тексту підтягнуто до ≥ 4.5:1, мінімальний розмір тексту 10–11px.

## Автоматичні суми зборів (Donatello)
Та сама ідея, що й `fundraising-sync` у lbk-admin, але без сервера: суми беруться під час збірки.

1. У `src/data/games.ts` додайте грі `fundraisingUrl` — посилання на ціль Donatello з параметром `?g=…`
   (кнопка «Поділитися» на сторінці цілі). Також мають бути `fundraisingGoal` і `fundraisingRaised` — вони
   лишаються запасними значеннями, якщо Donatello недоступний.
2. Під час `npm run build` модуль `src/lib/fundraising.ts` читає `donatello.to/<автор>` і підставляє
   актуальні «зібрано» та «мета». У лозі збірки видно рядки `[fundraising] <гра>: зібрано / мета`.
3. GitHub Actions пересобирає сайт щодня о 03:00 UTC (`schedule` у `.github/workflows/deploy.yml`),
   тож суми оновлюються без комітів. Запустити вручну: Actions → Deploy → Run workflow.

Щоб зібрати без мережі: `FUNDRAISING_SYNC=off npm run build`.
Коли збір завершено — поставте `fundraisingCompleted: true`.

## Прогрес із LBK Launcher
Під час збірки `src/lib/launcher.ts` бере з публічного API лаунчера
(`lbklauncher.com/api/games-list?authors=…`) переклад і редактуру у %, статус, версію й дату оновлення
для авторів «Little Bit» і «Солов’їна команда». Описи, обкладинки, теги, етапи «Малювання»/«Шрифти»
та збори лишаються з `games.ts`.

- Прив'язка гри: поле `launcherSlug` або адреса в `downloadUrl` (`lbklauncher.com/games/<slug>/…`).
- Статуси: `completed` → Готово, `in-progress` / `tech-improvement` → Ранній доступ,
  `planned` → У роботі (або Заплановано, якщо 0%). Переклад 100% у ранньому доступі показується як «Готово».
- **Ручний пріоритет:** `launcherSync: false` — гра бере цифри лише з `games.ts` (зараз: Dispatch,
  KH Birth by Sleep, Metal Gear & Metal Gear 2).
- У лозі збірки видно `[launcher] оновлено N з M` і ігри, яких немає на сайті.
- Без мережі: `LAUNCHER_SYNC=off npm run build`.

## Закинутий етап
«Закинуто» — не окремий статус, а позначка на етапі. Статус гри лишається звичайним
(наприклад, «Готово», якщо грати можна).
```ts
status: "done",
abandonedStage: "Редактура",
abandonedReason: "Вийшов офіційний український переклад…",
launcherSync: false,
```
Картка показує цей етап закресленим і заштрихованим, сторінка гри — червоний блок із причиною.
